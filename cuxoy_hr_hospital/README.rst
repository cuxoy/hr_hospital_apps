HR Hospital
===========

HR Hospital is an educational hospital management module for Odoo 19.

Features
--------

* Doctors management
* Patients management
* Patient visits
* Disease hierarchy
* Doctor qualifications
* Personal doctor history
* Wizards
* PDF reports
* Access rules
* Ukrainian translation
* Automated tests

Installation
------------

#. Copy the module to your custom addons directory.
#. Update the apps list.
#. Install the HR Hospital module.

Usage
-----

Open the Hospital application from the main menu.
