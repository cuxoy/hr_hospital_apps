HR Hospital

HR Hospital is an educational Odoo 19 module for managing doctors, patients, visits, diseases, doctor history, reports and access rules.

Features

  • Doctors and doctor qualifications
  • Patients with medical information
  • Patient visits with statuses
  • Disease hierarchy
  • Doctor assignment history
  • Calendar, kanban, pivot and graph views
  • PDF doctor report
  • Wizards
  • Security groups and record rules
  • Ukrainian translation
  • Automated tests
